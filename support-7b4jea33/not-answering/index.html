SAM does not answer

Work down this list, from the top. Most causes fix themselves or take a minute.

1. What does SAM send back?

  • Nothing at all: go to 2.
  • Only "Acknowledged": your message arrived, but Claude can't think right now. Either SAM is logged out of Claude (see 3) or your subscription's usage limit is reached; that resets by itself within a few hours. In the Claude app: menu (three lines, top left) > your name (bottom left) > Usage shows the limit.
  • "SAM is logged out of Claude": see 3.
  • "SAM is stuck on a question when it starts", with numbered choices: see 4.

2. Nothing comes back

  1. Wait 5 minutes. SAM checks itself every 5 minutes and fixes most problems on its own (a restart, a startup question it knows).
  2. Check the unit has power and its network (cable, or your home wifi is on).
  3. Unplug the power, wait 10 seconds, plug it back in. SAM starts by itself within a few minutes.
  4. Did a new router or wifi password come in? The unit's own wifi SAM-unit name appears after about 5 minutes. Join it with the clearance code and fix the network in setup step 1.
  5. At home: ask for the setup page (router app, look for the unit, open http://its address:8765) and press Start in step 7. Send "hi" after one minute.

3. Logged out of Claude

Send /login to SAM and follow Sign in to Claude again. Works from anywhere.

4. A question with numbered choices

When Claude starts, it sometimes asks a question first, for example about a new mailbox SAM has added. SAM answers the questions it knows by itself. A question it doesn't know comes to you on Telegram, word for word, with the choices numbered.

  1. Read the question. Reply with the number of your choice, nothing else.
  2. SAM presses it and checks what comes next. A second question comes the same way.
  3. SAM says it got past the questions and starts. It answers within a minute.

Not sure which number? Ask us first at @Contact_SAM_bot, with a screenshot of the question. If you don't answer within 30 minutes, SAM tries again later by itself.

Common question: "New MCP server found in this project". That is a mailbox or connector SAM added. "Use this and all future MCP servers in this project" is the usual answer.

5. SAM older than version 0.5

Ask SAM "what version are you?", or see the update message. Before 0.5 there is no /login and no phone answer for startup questions; it needs the unit's own screen, keyboard and mouse:

  1. Open Terminal on the SAM desktop.
  2. Type cd ~/"Name notes" (your assistant's name), Enter.
  3. Type claude, Enter, and wait about 10 seconds.
  4. Answer the question it shows: arrow keys to choose, Enter to confirm. For "New MCP server found", choose Use this and all future MCP servers in this project.
  5. When Claude is ready, type /exit, Enter. Close the Terminal.
  6. Setup page, step 7, Start. Send "hi" after one minute.

Then install the next update when SAM offers it (reply Yes, install now).

Still not answering?

Message @Contact_SAM_bot with: what you see (or nothing), since when, your unit name (on the label), and a photo of the setup page or screen if you can. Nobody can log in to your unit from outside, so photos help us help you.
